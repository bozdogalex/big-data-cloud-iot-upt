# Laboratory map

14 sessions of two academic hours.

1. **Introduction to Big Data and IoT** — Connect sensors, data storage, processing and analytical results through a biomedical example.
2. **Storage formats and analytical SQL** — Compare CSV and Parquet and query telemetry with SQL.
3. **Data quality and integration** — Identify duplicates and missing observations and interpret their effects.
4. **Batch and distributed processing** — Use transformations, aggregation and joins to process data.
5. **Performance and incremental updates** — Compare processing choices using runtime and equivalent results.
6. **IoT ingestion and replay** — Understand producers, consumers, event timestamps and message arrival.
7. **Stream processing** — Explain time windows, late arrivals and replay behaviour.
8. **Temporal features and ML evaluation** — Build temporal features and recognise data leakage.
9. **ML workflows in the cloud** — Run and evaluate a baseline and compare data-preparation choices.
10. **Document ingestion and retrieval** — Prepare documents while preserving source metadata.
11. **RAG evaluation observability and security** — Trace an answer to evidence and investigate failures.
12. **Reproducible execution** — Reproduce a workflow and verify selected output properties.
13. **Integrated troubleshooting** — Diagnose one failure in a familiar pipeline.
14. **Project presentations** — Present results and explain individual decisions and contributions.
