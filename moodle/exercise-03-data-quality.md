# Optional exercise — How complete is this minute?

Complete the guided Lab 03 heart-rate notebook first.

## Task

Flag minutes containing fewer than 54 of the expected 60 readings. Compare that result with a rule requiring all 60 readings. Explain which minute is flagged and why duplicate removal does not restore missing observations.

## What to save

Save your notebook with the comparison table and add a short explanation in your own words. Include the threshold you used and one limitation of interpreting an average without its reading count.

## Connection to project work

You can reuse this check if your project needs to detect incomplete data. The project brief will explain when it counts towards a milestone.
