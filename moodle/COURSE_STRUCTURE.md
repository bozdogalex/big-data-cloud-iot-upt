## Assignment setup

The two Assignment activities are submission points within **one project**.
The supplied descriptions are instructor drafts. Keep the activities hidden
until project requirements, assessment criteria, individual/group settings and
deadlines are settled. Do not invent dates or separate grade weights for recording.
The discipline's fixed weighting remains 60% examination and 40% laboratory.

## Lab 03 learning sequence

1. Before class: read the introduction and predict what an average can conceal.
2. In class: run the notebook, compare counts and averages, inspect duplicate removal.
3. After class: optional threshold exercise and a short interpretation, with questions
   handled through the forum or next laboratory discussion.

This sequence uses the existing notebook and exercise; no additional graded
submission is needed for the introductory prediction or optional exercise.

## Fast setup when service returns

1. Enable course editing and create the sections in the order above.
2. Add Page resources using the corresponding Markdown or generated HTML fragments.
3. Add the repository and notebook URL resources and the discussion forum.
4. Create the two hidden Assignment drafts in Project.
5. Check Lab 03 in student view: preparation, notebook link, follow-up exercise.
6. Attach presentation files later. Avoid empty File resources.
