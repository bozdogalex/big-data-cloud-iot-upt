# Lab 03 — Data quality

Open `03_data_quality.ipynb` and run the cells in order. It includes the guided explanation, real data excerpt, deliberate duplicate/missing messages, plots and reflection questions. No data download or cloud service is needed during the exercise.

The optional task asks students to flag incomplete minutes using a simple threshold. It is separate from the guided walkthrough and does not create a mandatory weekly assignment.

From the repository root, start the environment with `docker compose up --build`. Open the localhost URL containing the token shown in the logs, then navigate to `labs/03-data-quality/03_data_quality.ipynb`.

The notebook saves `outputs/comparison.png` and `outputs/comparison.csv`. See `data/README.md` for source attribution and modifications.
